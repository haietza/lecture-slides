Core CS Review

  • Abstraction is a concept that sits at the very heart of computer science.
  • Why do we need it? Because human working memory is limited. Abstraction reduces cognitive load, makes code reusable, and enables massive systems to be built safely.
  • Think about the java.util package. You use ArrayList without worrying about how the underlying array resizes itself.
  • You interact with an interface, not the complex implementation.

Abstraction

  • Simplifying complexity by focusing on what matters and hiding what doesn’t.
  • Computers are built on layered abstractions:
    • Hardware hides electrical details.
    • Operating systems hide hardware details behind files and processes.
    • Programming languages hide machine code.
    • Functions hide implementation behind clean interfaces.
  • This is exactly like using a refrigerator: you just open the door and get food, without needing to know the thermodynamics of the compressor.
